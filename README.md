# Penetration Tester Job Role Path

Personal study notes from the Hack The Box Penetration Tester Job Role Path.

## Included modules

This repository currently covers modules 01 through 09, including the penetration-testing process, enumeration, footprinting, web information gathering, vulnerability assessment, file transfer, shells and payloads, and Metasploit.

## Intentionally excluded

`10_Password Attack/` is deliberately excluded because it is still in progress and is listed in `.gitignore` to prevent accidental publication.

## Purpose

These notes are published as a learning portfolio. Commands and techniques must be used only in systems and labs where testing is authorized.
